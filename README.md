Este é o principal projeto que desenvolvi utilizando JavaScript puro, com o objetivo de colocar em prática conceitos fundamentais do desenvolvimento frontend.

A ideia foi simular um sistema simples de gerenciamento de clientes, trabalhando desde a manipulação de dados até a atualização dinâmica da interface.

🚀 Funcionalidades
Cadastro de novos clientes
Edição de informações
Remoção de registros
Busca de clientes em tempo real
Controle de status (Active, Inactive, Disabled)
Atualização da interface sem recarregar a página
💾 Persistência de dados

Os dados são armazenados utilizando o localStorage, permitindo que as informações continuem disponíveis mesmo após atualizar ou fechar o navegador.

🧠 O que aprendi com esse projeto

Esse projeto foi muito importante para consolidar alguns conceitos na prática:

Manipulação de DOM com JavaScript
Estruturação de lógica para operações CRUD
Gerenciamento de estado sem frameworks
Organização de código em aplicações frontend

🔧 Tecnologias utilizadas
HTML
CSS
JavaScript
🎯 Objetivo

Mais do que apenas criar um CRUD, o objetivo foi entender como uma aplicação funciona por trás, sem depender de frameworks.
